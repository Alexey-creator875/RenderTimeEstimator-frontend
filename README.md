# RenderTimeEstimator - Frontend

Одностраничное приложение для просмотра конфигураций серверов рендер-фермы
(услуг «Расчет времени рендера 3D-сцены на рендер-ферме»).

**Стек:** React, TypeScript, Vite, React-Bootstrap, React Router.

## Нижняя навигационная панель

Панель закреплена внизу на всех страницах и состоит из четырёх вкладок:

- **Лента** — открывает ленту с первой услугой из текущего списка.
- **Добавление** (неактивна) — добавление новой услуги.
- **Плитка** — открывает страницу со списком услуг.
- **Вход** (неактивна) — авторизация пользователя.

## Страница «Плитка» (`/`)

Список услуг в виде карточек в два столбца.

**Фильтр по оперативной памяти:**
- подпись «Объём RAM: min – max ГБ» показывает выбранный диапазон;
- левый ползунок задаёт нижнюю границу, правый — верхнюю (от 8 до 128 ГБ), левый не может быть правее правого;
- кнопка «Применить» оставляет в списке только услуги, у которых объём RAM попадает в диапазон.

**Карточка услуги:**
- изображение (если его нет или оно не загрузилось, показывается изображение по умолчанию);
- название процессора;
- количество ядер и объём RAM;
- количество лайков;
- клик по карточке открывает страницу «Лента» с этой услугой.

Если под фильтр не попала ни одна услуга, выводится сообщение «Ничего не найдено».

## Страница «Лента» (`/detail/:id`)

Полноэкранное видео выбранной услуги (если видео нет, воспроизводится видео по умолчанию).

**Поверх видео:**
- название процессора;
- описание услуги, свёрнутое до двух строк;
- кнопка «ЕЩЁ» разворачивает описание, кнопка «СВЕРНУТЬ» сворачивает его обратно (если описание короткое, кнопки нет);
- справа колонка: количество лайков, количество ядер, объём RAM и кнопка «Далее» со стрелкой;
- кнопка «Далее» открывает следующую услугу из списка, после последней возвращает к первой.
